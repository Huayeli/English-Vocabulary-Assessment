# 需求基线

> 2026-08 调整：访问方式已从“账号 + 套餐”改为“激活码”模式（无登录、无用户信息）；管理后台收敛为全局统计、题库管理、测试管理、激活码管理四个模块；错词本已移除。以下历史章节中涉及账号/邮箱/套餐/错词的内容以本文顶部说明为准。

## 1. 项目目标

开发一个基于 BNC/COCA 词频等级的英语词汇量智能评估系统，通过五选一选择题完成自适应测试与等级验证，输出词汇量评估报告。

## 2. 核心等级体系

系统核心等级采用 BNC/COCA 原始 K 等级，共 11 个固定等级，1k-10k 完整递进不跳档：

| 系统等级 | 对应 BNC/COCA 词表 | 词数 |
|---|---|---|
| 1K | 1k 词表 | ~1000 |
| 2K | 2k 词表 | ~1000 |
| 3K | 3k 词表 | ~1000 |
| 4K | 4k 词表 | ~1000 |
| 5K | 5k 词表 | ~1000 |
| 6K | 6k 词表 | ~1000 |
| 7K | 7k 词表 | ~1000 |
| 8K | 8k 词表 | ~1000 |
| 9K | 9k 词表 | ~1000 |
| 10K | 10k 词表 | ~1000 |
| 10K+ | 11k-25k 词表（最高等级） | ~15000 |

规则：

- 1K-10K 各档一一对应同名 BNC/COCA 词表，等级序列 K1→K2→K3→K4→K5→K6→K7→K8→K9→K10→K10P，不跳档。
- 10K+ 为最高等级，包含超过 10K 范围的全部词汇。
- 自适应测试、等级验证测试、词汇量评估全部基于这 11 个等级。
- CEFR 等级只作为测试报告中的辅助参考展示，不参与核心算法。

建议 CEFR 辅助映射：1K→A1、2K→A2、3K→B1、4K→B1、5K→B2、6K→B2、7K→B2、8K→C1、9K→C1、10K→C1、10K+→C2。

## 3. 功能模块需求

### 3.1 词库管理模块

管理单词数据：单词、K 等级、中文词义。

- 导入词库（BNC/COCA + ECDICT 合并生成初始词库）
- 查询单词（关键词、等级筛选、分页）
- 修改单词（等级、词族、状态）
- 删除单词（级联删除词义与关联题目）

### 3.2 单词词义管理模块

一个单词可对应多个中文含义（一词多义）。

示例：

```
run:
- 跑
- 运行
- 经营
```

### 3.3 四选一测试题生成模块

根据单词生成选择题：

```
单词：abandon
问题：abandon是什么意思？
选项：1 个正确答案 + 3 个错误干扰项
```

生成规则：

- 正确答案来自目标单词的中文释义。
- 干扰项从其他单词的中文释义中抽取，优先同等级或相邻等级，且内容与正确答案相关（共享关键词）但不一致，作为混淆项。
- 不得使用目标单词自身的其他释义作为干扰项（避免歧义）。
- 选项文本不得重复。

采用四选一模式，不采用认识/不认识模式。

### 3.4 基础自适应测试模块（核心）

测试规则：

- 总题数固定 30 题。
- 初始测试等级为 3K。
- 连续答对 4 题：提升一个等级（如 3K → 4K）。
- 连续答错 2 题：降低一个等级（如 5K → 4K）。
- 等级序列：1K → 2K → 3K → 4K → 5K → 6K → 7K → 8K → 9K → 10K → 10K+。
- 边界：1K 答错不再降级；10K+ 答对不再升级。

测试过程中保存：用户 ID、单词、当前等级、用户答案、是否正确、答题时间。

### 3.5 词汇量评估模块

30 题结束后，根据用户表现计算：

- 当前 K 等级（测试结束时的最终等级）
- 各等级掌握率（该等级答题正确数 / 该等级答题数）
- 预计词汇量

预计词汇量公式：

- 预计词汇量 = 已通过档位累加 + 当前档词汇量 × 当前档掌握率。
- 档位基准：K1=0、K2=1000、K3=2000、K4=3000、K5=4000、K6=5000、K7=6000、K8=7000、K9=8000、K10=9000、K10P=10000；当前档词数：1K-10K 各 1000、10K+ 为 15000。
- 当前档无已答题目时退回整体正确率；仍无数据取 0.5。

示例：最终等级 5K、5K 段掌握率 60% → 预计词汇量 4000 + 1000×0.6 = 4600。

### 3.6 等级验证测试模块

基础测试结束后，用户可主动选择验证某个等级（1K/2K/3K/4K/5K/6K/7K/8K/9K/10K/10K+）。

- 指定等级抽取 30 道题。
- 正确率达到 80% 及以上（≥80%）认为达到该等级。
- 需要套餐权限（月卡/年卡）。

### 3.7 测试报告模块

生成报告，包含：

- 测试时间
- 测试类型（自适应 / 等级验证 / 错词再测）
- 测试题数
- 正确率
- 当前等级
- 预计词汇量
- 各等级掌握情况
- CEFR 参考（辅助展示）

### 3.8 错词本模块

保存用户错误单词：单词、所属等级、错误次数、正确释义。

- 同一用户同一单词只保留一条记录，错误次数累加。
- 查看错词（按错误次数排序）
- 再次测试（从错词本抽 10 题）
- 单词语义复习 / 标记已掌握移除

### 3.9 用户系统

- 注册：用户名 + 密码 + 邮箱（可选绑定）。
- 登录方式一（主要）：用户名 + 密码。
- 登录方式二（辅助）：邮箱验证码登录（需先绑定邮箱）。
- 用户主页显示：当前词汇量、当前等级、历史测试、错词数量。

### 3.10 套餐权限系统

| 功能 | 免费体验 | 单次测试 | 月卡 | 年卡 |
|---|---|---|---|---|
| 自适应测试 | 每日 1 次 | 完整 30 题（剩余次数制） | 无限 | 无限 |
| 报告 | 基础报告 | 详细报告 | 详细报告 | 详细报告 |
| 等级验证 | - | - | 支持 | 支持 |
| 错词本 | - | - | 支持 | 支持 |
| 历史记录 | - | - | 支持 | 支持 |

暂时只实现权限管理，不开发支付。套餐调整由管理员后台操作（开发期代替购买）。

### 3.11 管理员系统

1. 用户管理：查看用户信息、测试次数、当前等级、套餐；调整套餐。
2. 词库管理：管理单词、K 等级、词义。
3. 题库管理：管理题目、答案、干扰项。
4. 数据统计：用户数量、测试次数、平均词汇量、等级分布。

## 4. 邮箱验证码规则

- 6 位数字验证码。
- 有效时间 5 分钟。
- 验证成功后立即失效。
- 同一邮箱 60 秒内不能重复发送。
- 使用 163 邮箱 SMTP 发送。
- 用途：快捷登录、找回账号（重置密码）、账号绑定、后续通知。

## 5. 安全要求

- 数据库只保存加密后的密码（bcrypt），不保存明文。
- 所有受保护接口通过 JWT 鉴权，权限限制在后端强制执行。

## 6. 技术栈

- 前端：Vue3 + TypeScript + Vite + Pinia + Vue Router + Axios
- 后端：Node.js + TypeScript + Express + Prisma
- 数据库：SQLite
- 邮件：nodemailer（163 SMTP）
