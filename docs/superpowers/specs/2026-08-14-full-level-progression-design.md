# 完整等级递进 + 词汇量估算 + 答题字体 设计文档

> 日期：2026-08-14

## 目标

1. 等级序列完整递进：`K1 → K2 → K3 → K4 → K5 → K6 → K7 → K8 → K9 → K10 → K10P`，1k–10k 每一档都进入系统，不再跳过 4k/6k–9k。
2. 词汇量估算从“等级基准值一刀切”改为“已通过档位累加 + 当前档正确率折算”。
3. 答题时英文单词字体改为 Times New Roman。

## 背景

- 源词表 `data/output.json` 含完整 1k–25k 共 25 档，每档约 1000 词。
- 当前系统只定义了 6 档（K1/K2/K3/K5/K10/K10P），seed 把 4k、6k–9k 共约 5001 词整档丢弃，导致 K3 直接跳 K5。
- 当前词汇量估算 `LEVEL_RANK[finalLevel] * 1000`，考到 K5 即固定输出 5000，与答题表现无关。

## 设计决策

### 1. 等级体系（11 档）

| 系统等级 | BNC/COCA 词表 | 词数 | CEFR |
|---|---|---|---|
| K1 | 1k | ~1000 | A1 |
| K2 | 2k | ~1000 | A2 |
| K3 | 3k | ~1000 | B1 |
| K4 | 4k | ~1000 | B1 |
| K5 | 5k | ~1000 | B2 |
| K6 | 6k | ~1000 | B2 |
| K7 | 7k | ~1000 | B2 |
| K8 | 8k | ~1000 | C1 |
| K9 | 9k | ~1000 | C1 |
| K10 | 10k | ~1000 | C1 |
| K10P | 11k–25k | ~15000 | C2 |

- `LEVEL_SEQUENCE`、`LEVEL_RANK`、三个 controller 的等级白名单、reliability 的 rank、CEFR 映射全部补齐。
- `bncToLevel` 增加 4k–9k 映射，seed 后全量 25001 词入库，不再有 skipped。

### 2. 词汇量估算公式

```
词汇量 = floor(finalLevel) + band(finalLevel) × mastery(finalLevel)
```

`mastery(level)` = 该等级已答题目中答对的比例；若该等级无已答题目，则退回整体正确率（仍无数据时取 0.5）。

| 等级 | floor（已通过累加） | band（当前档） | 100% 正确 | 50% 正确 |
|---|---|---|---|---|
| K1 | 0 | 1000 | 1000 | 500 |
| K2 | 1000 | 1000 | 2000 | 1500 |
| K3 | 2000 | 1000 | 3000 | 2500 |
| K4 | 3000 | 1000 | 4000 | 3500 |
| K5 | 4000 | 1000 | 5000 | 4500 |
| K6 | 5000 | 1000 | 6000 | 5500 |
| K7 | 6000 | 1000 | 7000 | 6500 |
| K8 | 7000 | 1000 | 8000 | 7500 |
| K9 | 8000 | 1000 | 9000 | 8500 |
| K10 | 9000 | 1000 | 10000 | 9500 |
| K10P | 10000 | 15000 | 25000 | 17500 |

现有 K10P 公式（10000 + 正确率 × 15000）是上述公式的特例，合并为统一实现。满分上限保持原刻度（K5≈5000、K10≈10000、K10P≈25000）。

### 3. 答题字体

- `QuestionCard.vue` 的英文单词（`.q-word`）改为 `font-family: "Times New Roman", Times, serif`。

### 4. CAT 规则调整（后续确认追加）

- 连对/连错计数按档重置：升级或降级后重新累计，每个等级至少连对 3 题才放行，避免中间档只测 1 题。
- 总题数保持 30（K3 出发升到 K10P 需要 24 题，30 题给 K10P 留 6 题采样）。
- 最终等级按掌握率判定：从 1K 向上连续达标（每档“答题 ≥ 3 题且正确率 ≥ 80%”）的最后一档，某档不达标即停止，更高档全对也不算；无达标档时回退到答题最多的档。
- 保持不动：重答机制（回改 + 历史重放）、等级波动异常判定。

## 验收标准

- `applyLevelRules` 按序递进：K3 连对 4 → K4；K4 连对 4 → K5；K5 错 2 → K4。
- `bncToLevel("4k".."9k")` 返回对应等级；seed 后库内 K1–K10 各约 1000 词、K10P 约 15000 词，总词数 25001。
- 词汇量估算随正确率变化（K5 段 50% → 4500，100% → 5000）。
- 前端验证选择器、后台词库、报告、统计展示 11 档；答题单词为 Times New Roman。
- 服务端全量测试与前端构建通过。
